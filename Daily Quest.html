HIJRI DATE

The Hijri date follows the Umm al-Qura calendar. Moon sighting can differ by a day, for example Bangladesh is often one day behind Saudi Arabia. Use -1 to move the date back one day.

REMINDERS

Remind for

Reminders only work while this page is open in a tab or app. A browser cannot wake a closed page. If notifications are blocked you still get an on-screen message, sound and vibration. Prayers you already logged are skipped.

SOURCE

When ON, the page asks the Aladhan API (api.aladhan.com) for the times and sends it your latitude and longitude. If the page is not allowed to go online, or the request fails, it uses the same standard method calculated on your device. The Prayer tab shows which source was used.
